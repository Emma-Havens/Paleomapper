Why is the program so slow?
It should, on average, take less than 10 seconds to plot a map. However, if it takes much longer than that, try plotting fewer map layers. The best layers to start with are “Plate_Polygons” and “Just_Coastlines”.

Why is the program crashing?
The crashing is a known problem that we are working on. It is caused by some conflicts between PaleoMapper's dependencies, so we are working with the developers of those libraries to resolve the bug. They are actively working on the issue and should release the solution in a couple of months (as of April 2026). When they do, it will require users to repeat some of the PaleoMapper installation steps because the fix will be a change to the environment, not the PaleoMapper code itself. Until then, our recommendation is to regularly save your progress via projects.

Several layers, though they are checked, don’t appear in the final map. What is going on?
The order of the layers (top to bottom) is important. Some of the layers, such as “background_fill” and “Plate_Polygons” are filled with solid shading and will “cover” layers that lie below. Make sure that “background color” is at the bottom of the stack and that “Plate Polygons” lies below the coastline and data points.

The background is filled in and only some of my polygons are plotted. What happened?
In some cases, most often in map projections with squished edges (like Orthographic), polygons are broken or inverted while plotting. This causes the screen to be partially or entirely filled, covering up polygons that were plotted before the error. Although it is inconvenient, the best solution is to change the input parameters. Consider using a different projection, or adjusting the central latitude/longitude if possible. If the problem persists, the problem layers should be plotted with a fill color of "none" to prevent polygon filling.

I input a color, but it's still plotting with the previous value/the default value. What's wrong?
The program is sensitive to capitalizations and extra spaces. Make sure the color input appears exactly as it does in the "Color Options" tab. Also be sure to click away from the box before running the program. If the program is run while your cursor is still active in the table cell, then the program doesn't have a chance to properly read in what you entered.

How do I plot my data points on the maps?
You can plot user-defined data on the maps by creating a comma-delimited file in Excel (or a text processor) with a list of the data localities in the format of the file “Major_cities.csv”. You need to specify the modern latitude and longitude, and symbol type. You can also add descriptive text strings to the map or numeric labels. For more detailed instructions see the PaleoMapper User Manual.

Where are my files saving to?
All output files, regardless of the specified name, are saved to the folder where the active project file is located.
